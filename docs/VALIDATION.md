# Результаты проверки

Проверено в Linux x86-64, Python 3.12.14. Это проверка текущей облачной машины,
а не подтверждение работы Windows-сборки или восстановленной новой машины.

| Проверка | Результат |
| --- | --- |
| Повторяемая установка `bash scripts/cloud-install.sh` | Успех |
| `python -m pip check` | Несовместимых зависимостей нет |
| `python -m pytest -q` | 55 тестов прошли; ошибок и пропусков нет |
| `scripts/gui_smoke.py`, Qt offscreen | Успех: реальный loopback TCP, фоновые снимки, SQLite, шесть страниц, Leaflet/WebChannel, пауза/возобновление, ручная TCP-диагностика, корректное завершение |
| `scripts/map_smoke.py` | Успех: группировка, безопасные popup, выбор IP через Qt, лимит 100 из 1500 тестовых IP, очистка карты |
| Системный сбор TCP/UDP через psutil | Проверен на настоящих локальных сокетах тестового процесса |
| GeoIP2 Reader с официальной тестовой базой MaxMind | Проверен: тестовый IP `81.2.69.142` → Лондон, координаты 51.5142 / −0.0931, радиус 10 км |
| Wheel Python, включение ресурсов | Собран; локальный Leaflet, контуры стран, HTML/CSS/JS и ICO входят в пакет |
| Конфигурация облачной среды | `install_script` и `start_skill` сохранены в черновике; публикация не выполнялась |

MMDB для проверки скачана во временную папку из официального
[MaxMind-DB test-data](https://github.com/maxmind/MaxMind-DB/tree/main/test-data).
Это тестовая база, она не включена в исходники и не используется для
геолокации пользовательских соединений. Настоящая GeoLite2-City в этой
машине не установлена: приложение корректно показывает отсутствие базы.

В headless Qt выводились сообщения о недоступном GPU/Vulkan, системной D-Bus
и запрете изменения OOM score Chromium в контейнере. Функциональные проверки
завершились успешно, sandbox Chromium не отключался.

Не проверены здесь:

- Win32-рамка, taskbar, Snap, DPI на нескольких мониторах и реальные Windows-иконки;
- готовый Windows EXE и запуск на компьютере без Python;
- исполнение GitHub Actions;
- загрузка онлайн-тайлов OpenStreetMap (необязательная функция, выключена);
- длительная нагрузка во время игр и большой поток системных соединений;
- публикация конфигурации и восстановление приложения в новой облачной задаче.

ICMP, перехват пакетов и скорости трафика по процессам не реализованы.
Полный перечень целевых ручных проверок: [WINDOWS_CHECKLIST.md](WINDOWS_CHECKLIST.md).
