# Проверка на Windows 10/11 перед выпуском

В Linux нельзя подтвердить работу Win32 API и Windows EXE. Выполните эти
проверки на настоящей Windows 10 и Windows 11, включая обычную учётную запись.

- Запуск исходников и всей папки PyInstaller без установленного Python;
  корректный запуск QtWebEngineProcess, офлайн-карты и SVG-иконок.
- Кнопки свернуть, развернуть/восстановить, закрыть; Alt+F4.
- Перетаскивание за заголовок, двойной щелчок, восстановление из максимизации.
- Изменение размеров за четыре края и четыре угла, минимальный размер 980×640.
- Максимизация оставляет панель задач доступной; панель задач с каждой стороны,
  автоматическое скрытие; несколько мониторов и отрицательные координаты.
- Системный Snap при перетаскивании и Win+стрелки. Snap Layouts при наведении
  на кастомную кнопку максимизации в MVP не заявлен и требует отдельной реализации.
- DPI 100/125/150/175/200%, перенос между мониторами с различным масштабом;
  проверить границы hit-test, таблицы, размеры шрифтов, отсутствие системной рамки.
- Реальные TCP-соединения браузера; UDP-сокеты; процессы, к которым нет доступа;
  нормальное сообщение без обязательного требования административного запуска.
- PID reuse, исчезновение/возврат соединений, сохранение выбранной строки и
  прокрутки таблицы при большом количестве строк.
- Настоящая GeoLite2-City IPv4/IPv6; несколько процессов на одном IP;
  карта без базы, с повреждённым файлом и без интернета; кластеризация и фильтры.
- Отображение настоящих Windows-иконок EXE; недоступный путь не подменяется фиктивной иконкой.
- Пауза/возобновление, сон/пробуждение, закрытие во время DNS/TCP-проверки,
  отсутствие оставшихся процессов NetMap и блокировки SQLite.
- Сохранение/применение всех настроек, ограничение хранения, очистка с отменой
  и подтверждением, повторный запуск и защита от второго экземпляра.
- Длительное наблюдение во время игры: CPU, память и плавность GUI;
  пределы карты 100/500/1000, разрыв графика после сна.
- Онлайн-тайлы только после явного включения; видимое уведомление и атрибуция,
  выключение прекращает новые запросы. Проверить HTTP-кэш и условия OSM.
- Ручная диагностика успешного TCP-порта, закрытого порта, IPv6, NXDOMAIN,
  неверного ввода, отмены и недоступной сети. Метрики правильно подписаны как TCP.

Реализация рамки использует Qt startSystemMove и Win32 WM_NCHITTEST,
WM_NCCALCSIZE, WM_GETMINMAXINFO, pointer-sized Get/SetWindowLongPtr и
SetWindowPos. Наличие этого кода не заменяет перечисленные проверки.

Для 0.2 также проверить обе темы, переключение режимов без потери выбора,
первый запуск, пагинацию/CSV, сохранение старой базы и фоновую проверку MMDB.
