# Сторонние компоненты

- Leaflet 1.9.4, BSD-2-Clause. Код и CSS находятся локально в
  `netmap/resources/map/`. Полный текст лицензии: `leaflet-LICENSE`.
  Архив получен из npm и проверен по SHA-512 integrity из метаданных версии.
- Контуры стран: Natural Earth, общедоступные данные (public domain), масштаб 1:110m.
  Источник и SHA-256 исходного GeoJSON записаны в `VENDOR.json`.
  Границы являются картографическими данными источника, а не политическим утверждением.
- SVG-иконки навигации созданы для проекта, лицензия MIT.
- PySide6 / Qt / QtWebEngine: LGPLv3/GPLv3 или коммерческая лицензия Qt;
  Chromium включает дополнительные лицензии. При распространении EXE соблюдайте
  применимые условия Qt и включайте соответствующие уведомления/лицензии.
  Сборка использует динамические библиотеки в папке `dist/NetMap`.
- psutil: BSD-3-Clause; geoip2 и maxminddb: Apache-2.0.
- GeoLite2: база не включена. Получение и использование регулируются актуальными
  условиями MaxMind. Не публикуйте свою MMDB без проверки права распространения.
- Онлайн-тайлы: © OpenStreetMap contributors, условия ODbL для данных и
  [политика тайлов](https://operations.osmfoundation.org/policies/tiles/).
  Они выключены по умолчанию; офлайн-карта не требует этого сервиса.
