# NetMap 0.2 — Network Atlas

Версия 0.1 сохранена в `main`, изменения 0.2 разрабатываются в `netmap-0.2`.
Основа — тот же сборщик psutil, GeoIP2, SQLite WAL и TCP-диагностика.

## Что изменилось

- Горизонтальная навигация по пяти разделам. Настройки — отдельная кнопка
  в заголовке. Кнопки окна и Win32-рамка сохранены.
- Atlas Dark / Atlas Light с общими токенами цветов, шрифтов, отступов и состояний.
  Темы меняют также Leaflet и графики. Нет постоянной боковой панели.
- Простой / Эксперт: режим сохраняется; переключение не перезапускает сборщик,
  не меняет SQLite и не сбрасывает фильтры технической таблицы.
- Карта занимает основную область. Три компактных показателя, список последних
  адресов, фильтр программы. Панель открывается только по выбору и закрывается.
- Leaflet обновляет маркеры по ключу и сохраняет объекты, когда точки не меняются.
  Контуры стран перекрашиваются только при смене темы. Линии обновляются при
  изменении координат; лимит адресов применяется до передачи данных в Chromium.
- Простой список соединений группируется по программе. Локальные сокеты
  агрегированы, публичные IP доступны с действиями копирования, карты и истории.
  По запросу можно раскрыть исходные технические сведения.
- Экспертная таблица: прежние фильтры и устойчивый выбор, меню видимых столбцов,
  горизонтальная прокрутка, CSV и контекстные действия.
- Приложения: поиск, сортировка, сводка, география, история; переход к карте или
  соединениям программы. Экспертный режим добавляет таблицу исходных сокетов.
- История: страницы по 100 сеансов, общий счётчик, серверная сортировка всей
  выборки, фильтры по PID/IP/протоколу/программе. Простой режим группирует по
  программе и дате, сохраняя каждый сеанс отдельным раскрываемым пунктом.
- CSV экспортирует всю отфильтрованную историю, а не только текущую страницу.
  Запись выполняется в фоне через временный файл; значения, похожие на формулы
  электронных таблиц, экранируются. CSV имеет UTF-8 BOM для Windows Excel.
- Аналитика: 15 минут / час / день / сохранённая история. График показывает
  реальные снимки (до 360 репрезентативных точек), подсказки и временные оси.
  Программы/протоколы считаются по сеансам, география — по уникальным публичным IP.
  Новые IP определяются по первому появлению в сохранённой истории, а не по
  числу сокетов. Удалённая по сроку история не участвует в сравнении.
- Тематические настройки, дополнительные параметры в простом режиме,
  фоновая проверка MMDB перед сохранением. Несуществующая/повреждённая база
  отклоняется; требуется база City. Путь данных виден в настройках.
- Первый запуск: краткий двухшаговый мастер внутри окна. Его можно пройти
  без GeoLite2; база и внешние тайлы не загружаются автоматически.
- Общие уведомления с подробностями и закрытием, без traceback в основном UI.

## Совместимость данных

Схема SQLite остаётся версии 1: миграция не нужна. Существующие сеансы и
временные отметки сохраняются. Новые поля JSON-настроек имеют значения по
умолчанию; старые файлы загружаются без изменения остальных параметров.
При открытии программы старые активные наблюдения переводятся в завершённые,
как и в 0.1. Никакая история не удаляется из-за смены темы или режима.

## Проверки и ограничения

- 68 автоматических тестов, включая прежние 55: все прошли в Linux.
- GUI smoke: реальные локальные сокеты, история, карта/WebChannel,
  пауза/возобновление, TCP-проверка и завершение потоков.
- Map smoke: группировка, выбор, безопасные popup, лимит объектов, сохранение
  объектов между одинаковыми обновлениями и переход к IP.
- Atlas smoke: режимы, сохранение режима, все шесть страниц, история,
  светлая карта и окно 980×640 без наложения навигации.
- Windows DPI 125/150/200%, Win32-рамка, системные иконки и EXE требуют проверки
  на Windows 10/11. Linux-проверки не подтверждают поведение этих функций.
- Нагрузочный тест во время игр не выполнен. Аналитика обновляется раз в
  10 секунд только при открытом разделе; тяжёлые SQL/CSV/MMDB операции остаются
  вне GUI-потока. Длинный экспорт может задержать следующий снимок мониторинга.
- ICMP, байты/скорости по процессам и определение владельца сервера не добавлены.
- Исторический IP можно показать, если сохранены координаты; лимит карты может
  ограничить отображение. Старые записи без координат не геолоцируются задним
  числом автоматически. Онлайн-тайлы выключены по умолчанию и не проверены здесь.

Технический идентификатор наблюдения доступен в подробностях экспертного режима.
Число «подключений» в простом представлении означает число обнаруженных
сетевых сокетов, включая локальные и ожидающие; это объяснено в подсказке.
